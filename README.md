# Rock River Outfitters Child Theme

Client: Rock River Outfitters, a kayak and canoe livery on the Rock River in Oregon, Illinois.

Parent theme: Twenty Twenty-Five

Made by Travis Vogel for Content Management Systems 2, Week 3.

## What this child theme changes

- theme.json sets the brand from my style guide. The palette is Sandbar, Deep Forest, River Green, Driftwood, River Mist and Whitecap. The first four use the parent slugs base, contrast, accent-1 and accent-2 so the Twenty Twenty-Five patterns pick them up.
- Headings use Bitter and body text uses Manrope. Bitter is loaded from a woff2 file in assets/fonts/bitter. Manrope comes from the parent theme.
- Font sizes and spacing keep the parent slugs (small to xx-large, and 20 to 60) with rem values from the style guide.
- Buttons are River Green with white text and turn Deep Forest on hover. Quotes get a Driftwood left border in Bitter, and separators are Driftwood.
- templates/ holds the custom Home, Contact and Single Post templates from Lab 2. parts/ holds the custom header and footer.
- styles/night-paddle.json is a dark style variation for moonlight paddle events. It darkens the background, lightens the text and brightens River Green so buttons stay readable.
